# 学习笔记

本目录存放对本仓库的学习笔记：会话复盘、过程走查、以及"本仓库实际如何运转"的样例。

## 边界

- **不是 Agent Note。** 任何内容都不进 `.agents/notes/`，不使用 Agent Note 的 header 或骨架，也不构成决策记录。
- **不是待办入口。** 未承诺的灵感排队在 [`.agents/inbox/`](../inbox/README.md)；复盘中冒出的灵感落到那里，本目录只链过去。
- **不是消费者文档。** 面向采用者的持久合同写在 `README.md`、`docs/` 或 Agent Note——绝不写在这里。

## 条目语言

默认用中文写；术语、路径与命令保留英文。

## 布局

文件命名 `yyyy-mm-dd-topic.md`（日期为首次撰写日）。

不能离开本机的笔记放 `.agents/learning/private/`——同目录的 `.gitignore` 已忽略该子树：勿提交，勿指望随 kit 分发。

当笔记中的持久事实已被 Agent Note 或已发布文档吸收后，删除该笔记，或在文首标明已吸收——本目录绝不成为第二套权威来源。
